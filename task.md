# Screamer Reverse Engineering project

There is a DOS game named Screamer.
The game is installed on the host in GOG format. It's installation files (in GOG distribution) are provided.
The task is to reverse engineer project into rebuildable source code.
At first, it may support the same system as it was built for.
In perspective we should provide support for modern plaforms -- at least current host's platform for a start.

Gather all necessary information for the project and document it throughout.
